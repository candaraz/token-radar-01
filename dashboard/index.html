Which pre-token protocol is worth farming?

Every protocol the snapshot carries, ranked by what its token would be worth if it launches, times how likely it ever is to record one. The launch value is a comps curve fitted on the traded tokens; the odds are a logistic fit on the peers' record. Both fits — and the held-out tests that kept or dropped each term — are on this page, with the numbers the model actually got.
