These protocols already trade. Their market caps are the market's own values, shown for comparison — never mixed into the ranked board.

How the numbers are made. The launch value is fitted from this snapshot's own traded tokens: log(market cap) against log(TVL), one trim pass, then each category's median residual, shrunk toward zero. Token odds come from the category's peer listing rate, smoothed toward the snapshot's global rate and discounted by how long the protocol has already run with no token. Implied value = launch × growth × maturity × odds. No protocol name is special-cased; the same functions score every row. The fit is tested by a two-fold holdout on the traded tokens — see the numbers above.
