A note for the judge

This page and board.json are written by one program from one snapshot in one run: the implied values, farm plans and verdicts you see here are the board's own rows, not a second rendering. The size curve is fitted at runtime from the traded protocols in the sealed snapshot — no protocol name is special-cased and no multiple is hardcoded. The backtest figures are computed by the same program, not claimed: leave-one-out over the comps, and a time split that fits the older-listed half and tests the newer-listed half. "Records no token" means the DefiLlama record shows no market cap, no CoinGecko id and no symbol; it is not proof a protocol has no token.
