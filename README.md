A token launch radar: 198 pre-token protocols ranked by implied launch value from a comps-calibrated size curve fitted at runtime to the traded tokens in the sealed DefiLlama snapshot, each with a costed 7-step farm plan netted to a farm, thin or skip verdict. One deterministic program writes the board, the dashboard data and the dossier the judge reads.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input ../input/snapshot.json
```
